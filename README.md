# NeuroNetix

Mobilna aplikacja neuronowa dla code-d.j.pl

## Instalacja

```bash
git clone https://github.com/DamJanJot/neuro-netix.git
cd neuro-netix
```

## Struktura

- `public/` - aplikacja frontendowa
- `api/` - API backend
- `core/` - wspólny kod
- `config.php` - konfiguracja
